# Juniore Games — Landing Page

Landing page responsiva em HTML, CSS e JavaScript para a Juniore Games.

## Arquivos

- `index.html` — estrutura da página
- `style.css` — identidade visual e responsividade
- `script.js` — menu mobile, animações de entrada e ano automático
- `assets/logo.png` — logo enviada pelo cliente

## Como usar

1. Mantenha a estrutura de pastas.
2. Abra `index.html` no navegador para testar.
3. Para publicar, envie os arquivos para a hospedagem mantendo a pasta `assets`.
